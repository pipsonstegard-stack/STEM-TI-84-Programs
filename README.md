\# TI-84 Engineering and Physics Programs



A collection of TI-84 calculator programs designed to simplify engineering and physics calculations. This repository includes tools for mechanics, stress analysis, electromagnetism, and structural analysis.



The programs are written in TI-BASIC and are intended to serve as practical computational tools and educational references for engineering students.



\## Contents



\### Physics and Electromagnetism



Programs for calculating electric and magnetic fields, electric potential, and electrostatic forces.



| Program | Description |

|---|---|

| Sphere Electric Field | Calculates the electric field associated with a charged sphere using the implemented formula. |

| Charged Ring Field | Calculates the electric field and electric potential along the axis of a uniformly charged ring. |

| Charged Disk Field | Calculates the electric field and electric potential along the axis of a uniformly charged disk. |

| Infinite Sheet Field | Calculates the electric field produced by an infinite, uniformly charged sheet. |

| Coulomb Force | Calculates the electrostatic force between two point charges. |

| Magnetic Field of a Straight Wire | Calculates the magnetic field produced by a finite straight current-carrying wire. |

| Magnetic Field of a Circular Loop | Calculates the magnetic field components and magnitude associated with a circular current-carrying arc. |



\### Mechanics and Stress Analysis



Programs for analyzing stress states, torsion, and curved or composite beams.



| Program | Description |

|---|---|

| Torsional Shear Stress | Calculates shear stress in a solid circular shaft under torque. |

| Principal Stresses and Maximum Shear | Calculates the principal stresses and maximum in-plane shear stress for a two-dimensional stress state. |

| Principal Stress Angle | Calculates the principal stress orientation from the normal and shear stresses. |

| Stress Transformation | Calculates transformed normal and shear stresses for a specified rotation angle. |

| Circular Shaft Polar Moment of Inertia | Calculates the polar second moment of area for a hollow circular cross-section. |

| Curved Beam Stress | Estimates stress in curved beams with rectangular, trapezoidal, or circular cross-sections using the implemented equations. |

| Composite Beam Properties | Calculates the modulus-weighted neutral axis and second moments of area for a two-section composite beam. |



\*This list describes the current collection and may be updated as additional programs are developed.\*



\## Requirements



\- A compatible TI-84 graphing calculator.

\- Programs written in TI-BASIC.

\- Knowledge of the relevant physical quantities and units for the selected calculation.



Compatibility may vary between TI-84 calculator models and operating systems. Programs that use calculator-specific matrix operations or other specialized features may require additional adjustments.



\## Usage



1\. Navigate to the program you want to use.

2\. Open the `.8xp` file on a compatible calculator, if a compiled calculator file is provided. Otherwise, enter or transfer the TI-BASIC source code using a compatible tool.

3\. Run the program from the calculator's program menu.

4\. Follow the displayed prompts and enter the required quantities.

5\. Read the calculated results displayed by the program.



\### Units and conventions



Unless a program specifies otherwise:



\- Use SI units for physical quantities.

\- Enter angles in the units specified by the program.

\- Use consistent units throughout each calculation.

\- Observe the sign conventions used by the individual program.



For example, an electrostatics program generally expects charge in coulombs, distance in meters, and electric field in newtons per coulomb. A mechanics program may expect torque in newton-meters and dimensions in meters to produce stress in pascals.



\*\*Always check the individual program's input requirements before using its results.\*\*



\## Accuracy and Limitations



These programs are intended for educational use and rapid engineering calculations. They implement specific mathematical models and are not substitutes for independent verification.



\- Some calculations rely on idealized assumptions, such as uniformly distributed charge, idealized beam geometry, or linear-elastic material behavior.

\- Numerical results depend on the accuracy of the input values and the assumptions underlying each equation.

\- Calculator precision, rounding, and input errors may affect the results.

\- Some programs may have limitations regarding supported geometries, loading conditions, or material configurations.



Verify formulas, units, sign conventions, and results against appropriate references before relying on them in engineering work.
